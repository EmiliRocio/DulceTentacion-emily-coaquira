## Descripción del Negocio
Sistema de gestión para la pastelería "Dulce Tentación", que administra categorías de productos, productos (pasteles, postres), clientes y sus pedidos.

## Estructura del Proyecto
- `db/`: Scripts SQL (schema, seed, consultas)
- `pokeapi/`: Documentación de la PokeAPI
- `docs/`: Documentación de métodos HTTP y capturas
- `frontend/`: Aplicación web con Fetch a PokeAPI
